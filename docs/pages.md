## Home

Página de inicio, aqui te pregunta si quieres crear un nuevo proyecto o importar uno, o hacer login como administrador. (Quizas meto una opcion de proyecto nuevo en blanco y nuevo proyecto desde plantillas o esta opcion la meto en el dashboard).

## Dashboard

Menú principal, dividido en apartados (global, titulos, guardar/cargar...)

## Constructor

Aqui puedes hacer la pagina web (html, css, js)

## Login

Login para entrar como administrador y desbloquear la opción de creador de componentes

## Creador de componentes

Aqui puedes crear componentes para luego utilizarlos en constructor.

## Copiar / Descargar código

Se entra desde el dashboard, se muestran todos los archivos que vas a descargar, aqui puedes copiarlos o puedes darle a un boton de descargar (te descargar un zip)

## Información

Aqui estara la informacion de html, de todas sus etiquetas para que sirven y sus atributos. Tambien estara la informacion de css, temas sibre posicion, display y algunos mas (ej. como meter una x encima de una imagen)
