# Forms

GET /dashboard/forms

## Contenido

- Title
- Nuevo
- Lista de forms
    - Desplegable (Abrir, Editar, Exportar, Guardar(admin), Eliminar)

### Edit Form

- Nombre
- Cancelar
- Guardar

## Actions

- Nuevo -> Crea uno nuevo
- Abrir -> /editor
- Editar -> Abre edit form
- Exportar -> Exporta en json el form seleccionado
- Eliminar -> Elimina el form seleccionado
- Guardar(admin) -> Lo guarda en la base de datos
- Cancelar -> Sale del modo edicion sin guardar
- Guardar -> Guarda los nuevos datos editados
