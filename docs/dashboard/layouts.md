# Layouts

GET /dashboard/layouts

## Contenido

- Header
    - Title
    - Nuevo
    - Lista de headers
        - Desplegable (Abrir, Editar, Exportar, Eliminar)
- Footer
    - Title
    - Nuevo
    - Lista de headers
        - Desplegable (Abrir, Editar, Exportar, Eliminar)

### Edit layout

- Nombre
- Type
- Cancelar
- Guardar

## Actions

- Nuevo -> Crea uno nuevo
- Abrir -> /editor
- Editar -> Abre edit layout
- Exportar -> Exporta en json el layout seleccionado
- Eliminar -> Elimina el layout seleccionado
- Cancelar -> Sale del modo edicion sin guardar
- Guardar -> Guarda los nuevos datos editados
