# Components

GET /dashboard/components

## Contenido

- Title
- Nuevo
- Lista de components
    - Desplegable (Abrir, Editar, Exportar, Guardar(admin), Eliminar)

### Edit component

- Nombre
- Cancelar
- Guardar

## Actions

- Nuevo -> Crea uno nuevo
- Abrir -> /editor
- Editar -> Abre edit component
- Exportar -> Exporta en json el component seleccionado
- Eliminar -> Elimina el component seleccionado
- Guardar(admin) -> Lo guarda en la base de datosw
- Cancelar -> Sale del modo edicion sin guardar
- Guardar -> Guarda los nuevos datos editados
